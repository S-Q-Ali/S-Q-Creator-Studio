### Basic Usage:
```

```

```

### Ponytail Levels:
```
/ponytail-lite     - Minimal lazy mode
/ponytail-full     - Full lazy mode (default)
/ponytail-ultra    - Ultra lazy mode
/ponytail-help     - Show ponytail help
